### 1.2 핵심 조작 흐름 (User Interaction Flow)

#### 케이스 A: 영수증이 있는 경우 (AI 1:1 매칭)
1. 영수증 사진 업로드 ➔ Gemini AI가 일자(`10-22`), 상호(`홈플러스`), 금액(`125,000원`), 품목 추출.
2. 좌측 통장 목록 중 `금액(125,000원) & 일자(±2일)` 일치하는 통장 행에 **보라색 하이라이트** 및 매칭 카드 표시.
3. 실무자가 하단 도킹바의 자동 완성된 표준 적요 및 계정과목을 확인하고 `[⚡ 1초 매칭 확정]` 클릭.
4. 즉시 `vouchers`에 결의서가 확정 저장되고, 통장 거래는 `FULLY_MATCHED`로 전환되어 미매칭 목록에서 사라짐.

#### 케이스 B: 영수증이 없는 경우 (간편 퀵 결의)
1. 통장 내역 중 `삼화전기 150,000원` 출금 확인 (영수증 미첨부).
2. 통장 행 아래에 노출된 `⚡ [퀵버튼: 시설유지비]` 클릭.
3. 팝업 없이 적요가 `[삼화전기] 시설 유지보수 및 수리비`로 자동 채워지며 즉시 결의서 생성.
4. 노란색 뱃지 `[⚠️ 영수증 미첨부]`가 부여되며, 추후 영수증 업로드 시 자동 연계 가능.

#### 케이스 C: 분할 매칭 (1 영수증 : 다중 통장 출금)
1. 영수증 `350,000원` 선택.
2. 좌측 통장에서 `운영비 통장 200,000원`과 `식자재 통장 150,000원` 체크박스 2개 동시 선택.
3. 하단 도킹바에 `[합계 350,000원 = 영수증 350,000원 일치!] [다중 분할 매칭 확정]` 활성화.

# 2. 화면 2: 월별 수지 일계표 및 통장 잔액 대사 화면

W4C(희망이음) 월별 마감 입력을 위해 **1일부터 말일까지의 일자별 수입·지출 내역과 마감 잔액을 1원 단위로 검증**하는 화면입니다.

### 2.2 핵심 조작 흐름
1. **월별 전체 수지 일치 확인**: 상단 요약 카드에서 `당월 장부잔액 = 실제 통장잔액` 녹색 뱃지 확인.
2. **차액(불일치) 발생 시 추적**:
   - `🚨 불일치` 행 클릭 시, 해당 일자의 통장 출금 내역과 결의서 목록을 양옆으로 대조.
   - 누락된 전표나 미매칭 통장 거래를 찾아 원클릭으로 보정.
3. **W4C 엑셀 내보내기**:
   - 수지 대사가 완료되면 `[W4C 일괄 업로드용 엑셀 다운로드]` 클릭.
   - 희망이음 업로드 규격에 맞는 양식 파일 즉시 생성.

### 3.2 [모달] 동일 항 내 예산 목간 전용(Transfer) 입력 팝업
- **제약 규칙**: 사회복지시설 재무회계규칙상 **"동일 항 내의 목"** 간에만 전용 가능 (예: 인건비 항 내에서 '기본급' ➔ '제수당'). 항을 넘어서는 전용은 지자체 승인 또는 추경 사안임.
- **입력 항목**:
  1. 전출 과목 선택: `[인건비 > 기본급]` (현재 잔액: 10,000,000원)
  2. 전입 과목 선택: `[인건비 > 제수당]` (동일 항 내 과목만 드롭다운에 노출)
  3. 전용 금액: `[2,000,000] 원`
  4. 전용 사유: `야간가산 근무자 증원에 따른 야간근무수당 부족분 충당`
- **결과**: `BudgetTransfers`에 자동 기록되고, 법정 양식인 **[예산전용조서 PDF/인쇄본]** 즉시 생성.
